เอกลักษณ์ตรีโกณมิติที่สำคัญ

1. เอกลักษณ์พีทาโกรัส
  • sin²θ + cos²θ = 1
  • 1 + tan²θ = sec²θ
  • 1 + cot²θ = csc²θ
2. สูตรมุมผลบวกและผลต่าง
  • sin(A ± B) = sinA cosB ± cosA sinB
  • cos(A ± B) = cosA cosB ∓ sinA sinB
  • tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA tanB)
3. สูตรมุมสองเท่า (Double Angle)
  • sin(2θ) = 2sinθ cosθ
  • cos(2θ) = cos²θ - sin²θ = 1 - 2sin²θ
  • tan(2θ) = 2tanθ / (1 - tan²θ)
4. โคฟังก์ชัน (Co-functions)
  • sin(90° - θ) = cosθ
  • cos(90° - θ) = sinθ
  • tan(90° - θ) = cotθ
